# Buttersea™ Next.js Application

A high-performance Next.js application built with **React 19**, **Next.js 16 (App Router)**, **TypeScript**, and a sleek **Vanilla CSS Design System**.

---

## 🚀 Quick Start

### 1. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 2. Build for Production
```bash
npm run build
```

### 3. Start Production Server
```bash
npm start
```

## 🛠️ Tech Stack & Features

- **Next.js 16 (App Router)**: Fast Turbopack bundling, React Server Components (RSC), and nested routes.
- **React 19**: Modern state hooks, server actions, and transition primitives.
- **TypeScript 5.8**: Strict type safety and `@/*` path mapping.
- **Vanilla CSS Tokens**: Clean, responsive, glassmorphism-enhanced design with dark and light mode toggle.
- **Lucide Icons**: Crisp, modern icon set.
